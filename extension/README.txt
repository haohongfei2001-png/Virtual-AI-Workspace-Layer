VAIWL Host 开发包使用说明

本包尚未完成 Free 验收，不是正式发布版。具体构建类别见本文件开头；
build-manifest.json 记录源码与文件哈希，不能作为功能通过证明。

安装与检查
1. 使用独立测试 Profile。离线包只用于本地测试站点；真实账户候选仅用于
   已获授权的专用 Profile，不因为安装扩展而扩大数据读取许可。
2. 将 ZIP 解压到准备长期保留的目录。在 chrome://extensions 打开开发者
   模式，选择“加载已解压的扩展程序”，选中含 manifest.json 的目录。
   记录扩展 ID、目录及原包；不要选择 ZIP 文件或外层包装目录。
3. 核对包的 SHA256SUMS，并在原仓库、已安装锁定构建依赖的环境中执行：
   node extension/package.mjs --verify "解压目录"
   目录应直接包含 manifest.json；ZIP 内不包含此校验工具。校验只读，
   不认证下载来源，也不代表 Free 功能或发布验收通过。缺文件、
   校验失败或构建类别不符时停止使用，不关闭校验或扩大网站权限。
4. 在支持的测试页面打开扩展图标查看状态。默认安全关闭包即使已登录，
   也不会打开完整增强界面。临时只读包只列出当前页面已显示的链接。
   原生搜索仍用于查找未被本地发现的聊天；列表末尾不代表全账户历史末尾。

数据和权限
临时只读模式只在当前文档及弹窗内存中处理已显示的原生标题和链接；
关闭弹窗丢弃列表，不验证账户、不打开历史数据库、不请求身份接口。
普通候选的身份核验只使用固定第一方入口；认证材料仅在受限内存短期使用，
不交给网页 MAIN 世界或界面，不写日志、数据库或备份。不要求复制 Cookie/token。
核验失败时不开放旧账户数据。当前候选不能证明完整账户历史或本人活动来源。

获授权的正常运行路径可在本机保存已接纳的项目/聊天元数据、成员证据、
活动记录、个人设置、工作集及用户明确选中的片段；不自动保存完整聊天正文。
元数据请求可能包含其他响应内容，实际读取仍需对应来源许可，不能把
“只保存元数据”解释为已获准读取任意正文。离线包仅处理测试夹具数据。
网站访问权限用于在指定宿主运行内容脚本和受限同源请求；webNavigation
用于识别文档与导航变化；若 manifest 包含 webRequest，用于正常请求的
上下文关联，不代表已经证实身份或取得完整响应目录。不新增凭据读取权限。
本包不提供云同步、遥测上传、付费 AI 调用或后台原生写入；点击原生入口
仍由宿主处理。不要把私人截图、备份、HAR 或完整响应上传为错误报告。

备份、升级与回退
升级前保存原安装包，并在有合法工作空间授权且功能可用时，使用增强界面的
人工备份。备份包含人工资产和必要引用，不是完整聊天镜像，也不恢复授权、
待执行动作或全部活动证据。临时模式没有备份入口；不能靠它导出旧账户数据。
备份文件可能含个人名称及主动保存的片段，请自行安全保管。

先在新暂存目录校验新包；保留原目录路径，更新其包文件后在扩展管理页
重新加载同一扩展，并确认 ID 未变。不要先卸载再升级。另一目录可能产生
另一扩展身份和独立存储，不能当作同 ID 升级或证明原数据丢失。

回退前必须核对目标版本是否支持当前数据库 schema 及 Native/Evidence/
人工资产记录格式。版本号更旧或界面能打开都不能证明兼容。未经证明兼容，
停止回退并保留现包与数据；不要删库、修改版本字段或强迫旧 writer 写入。
已证明兼容的回退也使用原路径和同一扩展 ID，随后检查人工资产与原生操作。
恢复人工备份前先预览摘要并明确确认；结果未知时先检查，不自动重复恢复。

故障、停用与卸载
出现未核验、403 或连接失败时保留原生 ChatGPT 使用；不要反复刷新/重登，
不要绕过挑战。若宿主确实显示验证页面，由用户在原生页面处理。
增强层异常时使用其原生退出入口，或在扩展管理页停用扩展。停用不是备份。
卸载可能删除扩展本地数据；仅在确认已保全需要的人工资产后执行。卸载和
本地恢复都不会替你删除或恢复服务器聊天。当前版本的真实安装、跨设备、
物理输入法及完整恢复验收仍待完成，不能据此说明书宣称发布就绪。
