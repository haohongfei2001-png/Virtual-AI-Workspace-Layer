## 已固定的要求

原生数据/Project 不变、独立可逆投影、稳定 Workspace/系列/工作集、两种标题分离和原生聊天/输入/模型/工具保留。

| ID | 状态 | 用户本轮明确要求 |
|---|---|---|
| V2-REQ-01 | OWNER_REQUIRED | 以真实 ChatGPT 的视觉/交互为参照；不采用另一套品牌或 PAIA 视觉；清楚保留第三方身份 |
| V2-REQ-02 | OWNER_REQUIRED | 一个主题一张聚合卡片，内含紧凑列表；跨 Project/普通聊天；无对话大卡片/复杂嵌套 |
| V2-REQ-03 | OWNER_REQUIRED | 默认最近一个月，主题与内部对话都按可信用户新发送时间筛选；历史折叠、未知不造假；1/3/12/all 与当地今天锚定的前后分段；当前/固定可访问；切换不改归属/不删数据 |

批准依据为本轮用户完整增量要求；它不构成真实能力通过或正式实现授权。最近月段包含今天，历史段结束于前一边界前一天，按原示例实现，不再把自然月或固定 30 天当替代方案。
