## 决策记录格式

确认时在对应 ID 后记录实际选择、用户原话或明确批准来源、日期及受影响的规格/验收；未明确项保持待定。正式 UI 实施只要求触及项确认，不让尚未选定的云供应商阻塞账户与恢复验证。

技术事实不交给用户投票：宿主 identity 是否能验证、Shadow DOM 是否足够隔离、禁用后是否能恢复等，必须由 R0 证据决定。不能问用户是否“接受”把未验证能力标成 PASS。
