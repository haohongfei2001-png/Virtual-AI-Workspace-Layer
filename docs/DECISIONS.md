产品分级及Free优先为用户明确决定。这里登记决定和历史去向，不是另一份执行计划。工程要求已写入各正文；完整依赖只在[DEVELOPMENT_PLAN](DEVELOPMENT_PLAN.md)。

## 4. 不预先批准的事项

实际ChatGPT数据渠道/原始时间/Project自动操作能力需要证据，不能靠设计表决；真实账号/发送/PAIA/模型/费用/同步/发布许可没有自动扩大。Pro定价与提供商未选。本轮不需要重新询问Free/Pro方向，也不将临时无数据或工具缺写权限包装成实现完成。
