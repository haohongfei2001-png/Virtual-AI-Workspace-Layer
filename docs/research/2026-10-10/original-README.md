# ChatGPT 工作空间重构扩展 · 研究交付

本包只含产品研究与交互原型。没有扩展安装包，没有连接真实 ChatGPT，没有 GitHub 修改。

## 阅读与体验

在桌面 Chrome 中打开 `research.html` 阅读完整报告。打开 `prototype.html` 体验单文件原型；不需要 npm、服务端、模型账户或浏览器扩展权限。某些聊天客户端会把 HTML 当附件而不是运行页面，应在浏览器打开。

推荐体验路径：PAIA 工作区 → 输入板交互 → 修改显示名称 → 切换原生/派生 → 来源详情 → 归属纠错与撤销 → 设置中的模拟改名、账户切换与故障回退。搜索快捷键是 Alt/Option+K；Escape 关闭对话框。拖到另一个工作区默认是同时显示，不是移动原生 Project。

原生改名预览、AI 建议、历史导入、账户和工作集全部是模拟；不会修改实际数据。原型只在当前浏览器尝试保存自身演示状态，草稿仅在内存；浏览器拒绝本地保存时会提示。不输入真实私密内容。

## 文件结构

- `research.html`：带目录与来源跳转的完整研究报告。
- `research.md`：可移交后续开发的 Markdown 研究原稿；不是已批准 Canonical。
- `prototype.html`：无外部依赖的交互研究原型。
- `validation/VALIDATION.md` 与 `test-results.json`：验证范围、结果和限制。
- `validation/test_prototype.py`：20 个原型交互测试，不是实际扩展测试。
- `validation/*.png`：桌面与窄屏界面截图。

报告中的成功率、速度与精确率是未来实验目标，不是已获得的产品结果。现有原型20项通过只证明其模拟流程。实际账户绑定、合法数据获取、MV3恢复和原生功能保留仍是独立可行性门槛。
