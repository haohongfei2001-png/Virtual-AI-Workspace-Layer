使用 Python Playwright + 系统 Chromium 144.0.7559.96；桌面视口 1440×1000，窄屏视口 390×844。标准文件 URL 导航被本环境管理员策略阻止，未规避策略。改用 Playwright 的 `page.set_content` 把本轮生成的 HTML 作为内存页面进行正常 UI 渲染与测试；未连接真实网站。
