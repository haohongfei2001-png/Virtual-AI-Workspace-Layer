# 文档效力与批准边界

2026-10-11，v2.6。设计要求、具体解法与执行授权分别登记。

## 已确定的边界

REQUESTED_BASELINE：原生数据与Project不变；可逆语义投影；稳定Workspace／系列／工作集；原生与派生标题分离；原生聊天、输入、模型和工具保留。

OWNER_REQUIRED_V2_1：可靠用户新发送驱动、当地今天锚定的日历段；主题只在其最近活跃段出现；旧窗口始终依附父主题；时间后台化，无常驻日期／额外来源／计数，未知不伪造。

OWNER_REQUIRED_V2_3_TO_5：主题／窗口有结构层级；连续侧栏由用户控制；克制的稳定主题图标；旧窗口、近期溢出和未知不混淆；原生真实聊天而非重绘；顶部相邻返回，不改绑原生标志或浏览器返回。

OWNER_ADOPTED_V2_6：用户在完整讨论后明确“按照你的建议，修改”，采纳无常驻文字的图形回看、功能所有权与折叠分开、原生能力及状态不丢失、真实dot身份外观沿用、原生搜索／新聊天不被替换、原生账户独立和未知原生入口默认保留。当前规格为 [v2.6](NATIVE_FEATURE_PRESERVATION_V2_6.md) 及整合的 [INTERACTION_SPEC](INTERACTION_SPEC.md)。

PROPOSED：精确像素／列数／容量、图标首次可理解程度、宿主组件可重排性、模型／同步供应商等尚未获得证据的解法仍为提案。采纳方向不等于批准全部旧PD项或宣称真实能力已通过。

只允许本仓库设计／计划／治理与版本化离线原型及合成验证，经既有独立分支和Draft PR提交；不改main，不自动合并，不修改其他仓库或原研究档案。不授权正式扩展、R0真实宿主探针、私人账户／聊天、原生写入、付费模型、安装、同步服务或部署。原型中的native-fixture不是原生操作授权。
