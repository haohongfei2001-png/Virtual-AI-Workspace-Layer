# 文档效力与批准边界

日期：2026-10-10。状态：PROPOSAL_FOR_REVIEW；下列用户明确要求不再视为可选候选。

## 1. 三类效力

**REQUESTED_BASELINE**：原生数据和 Project 归属不变；独立可逆语义投影；稳定工作区、对话系列、当前工作集；原生/派生标题分离；导航重构而保留原生聊天、输入框、模型和工具。

**OWNER_REQUIRED_V2**：[CORE_EXPERIENCE_V2](CORE_EXPERIENCE_V2.md) 固定本轮明确要求的原生 ChatGPT 一致性、主题级卡片、可靠用户发送时间与滚动日历窗口。前台主题即已有 Workspace，不新增 PAIA Topic 体系。原生风格不是另一个品牌方案；卡片内紧凑列表与主题卡片不冲突。以上必须前置进入 R0/B/C，不仅是 C5/F 后期优化。

**PROPOSED**：具体布局密度/列数/展开行数、固定区域位置、工作集纳入策略、新建默认、模型供应商等解法。工程化展开不是实际运行证明，原型选择不自动批准。

**EXECUTION_AUTHORIZATION**：当前允许设计、版本化 HTML 原型及其合成验证材料在已有 Draft PR 增量提交。仍不授权 R0 宿主探针、真实账户/私人聊天、原生写入、付费模型、同步、安装、正式运行时或部署。前轮“只提交 Markdown”是历史范围，被本轮明确原型请求有限扩展，不扩展其他权限。

## 2. 优先关系

用户最新明确要求/安全边界 > 本文批准边界 > CORE_EXPERIENCE_V2 对应增量 > 已明确批准的决策 > 原有专题规格 > 依赖/验收 > 原始研究/原型参考。

旧研究中“不要对话级卡片墙”继续有效，不得扩大解释为禁止主题卡片。旧中性/蓝白原型、独立密度、只列少量工作区的冲突部分以 v2 为准。原研究原件不回写，保留追溯。

STATUS 是唯一任务状态，DEVELOPMENT_PLAN 是唯一依赖路线；DECISIONS 记录逐项确认。本次不引入第二套 R0、批准队列或正式产品 Canonical 完成声明。

## 3. 证据标签

| 标签 | 含义与限制 |
|---|---|
| ARTIFACT_VERIFIED | 原件/字节/哈希核对；不证明产品可用 |
| RESEARCH_SOURCE | 固定源码与官方资料的研究记录；动态信息需定向复核 |
| VENDOR_CLAIM | 厂商声明，不是独立实测 |
| PROTOTYPE_SIMULATION | 合成 UI/时间算法；不证明真实时间、账户、原生 DOM 或 PAIA 共存 |
| BROWSER_FIXTURE | 真实浏览器上的合成宿主；不等于真实 ChatGPT |
| LIVE_HOST | 获准清洁账户、精确版本的宿主实验证据；不能泛化到所有环境 |
| TARGET / NOT_RUN | 指标/未验证能力；不能写为通过 |

本轮新增 37 项 v2 模拟记录；旧 20/20 不重标为新通过。原型里的 verified_fixture 和 complete 是测试数据声明，不是实际时间来源/覆盖验证。页面、导出、AI、其他扩展消息仍是候选证据而非授权。

## 4. 决策与失败

只把本轮用户明确选定的要求升为 OWNER_REQUIRED；不能连带批准全部 PD 项。技术事实由实验决定，不要求用户“同意把未知记为通过”。单条高风险能力受阻只关闭依赖它的路径，不能把全产品拖入无限审计，也不能以进度为由用访问时间或私有接口偷换来源。
