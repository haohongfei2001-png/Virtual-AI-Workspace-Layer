# 隐私、权限、安全与恢复规格

状态：PROPOSED，当前本轮无私人数据访问、模型调用或原生写入。来源：原研究 §6、§10–15；动态平台/条款来源记录见 SOURCE_REGISTER，不视作本轮法律意见或实时认证。

## 1. 三重身份与范围隔离

分开维护扩展账户、当前宿主文档账户/原生组织、数据来源 scope。三者匹配且证据新鲜才显示敏感别名/工作区、持久读取、云处理或写入。Project 是该原生范围内的对象，不等于 account/workspace 安全范围。

同一 Chrome 可存在账户/组织切换；安装、profile、tab、邮箱标签、头像、最近聊天指纹不能单独证明隔离。OAuth 认证了扩展用户也不证明网页当前仍是该用户。

切换先清除当前敏感投影、撤销 document/epoch 任务和旧操作权，再等新身份；每个异步边界后验证，晚回包拒绝。未知时保持原生和空的敏感缓存视图。不得以“两个 JavaScript store”或手选 vault 宣称自动安全。

## 2. 最小数据与授权层

页面可见引用、持久用户文本索引、云 AI、原生改名、同步和 PAIA 读取分别告知。标题、工作区名、向量、关联和日志也可能敏感，“不读正文”不等于无隐私。

默认索引仅限已发送、已核验角色与归属的用户文本及必要元数据。助手正文、未发送草稿、附件/Project 文件不进入默认路径；临时聊天不持久/不云处理/不进入长期工作区。企业/托管 scope 默认关闭云推理与跨域同步，管理员限制优先。

当前轮次不获取任何真实用户样本。未来评测使用合成数据，或另外有明确授权且可撤回的材料；公开仓库不得留下真实内容或可反推身份的标识。

## 3. 数据渠道逐条裁决

| 渠道 | 可主张的边界 | 禁止跳跃 |
|---|---|---|
| 页面标题/链接 | 当前渲染可见引用 | 不能声称已读全文或全部历史 |
| 已渲染用户消息 | 经角色、路由、分支归属验证的部分 | 不补造被虚拟化/折叠内容 |
| 官方导出 | 用户提供且范围/schema 被验证的快照 | 不保证所有账户都有；不是原生恢复 API |
| 原生搜索 | 用户主动打开的结果可观察 | 不当作批量搜索爬虫 |
| 被动网络响应 | 单列必要性、安全、条款与实际协议实验 | 不因 PAIA 有 observer 就复制为默认全量读取 |
| 共享链接 | 独立共享引用，可达规则受原生约束 | 不当自有聊天，不推断原账户归属 |
| 未打开历史 | 未知 | 不后台开数百 tab、不调用未文档化历史接口 |
| OpenAI API 会话 | API 应用自己的会话语义 | 不用 key/OAuth 冒充网页历史授权 |

用户同意、Chrome permission、只读、开源、竞品存在都不能替代平台许可。R0-00 单列数据/条款路线审查，必要时要求书面澄清；某路线不成立就关闭该路线，而不是绕过限制。

## 4. 威胁与控制

| 威胁 | 必须控制 | 所需证据 |
|---|---|---|
| 账户切换/旧回包 | epoch/current binding/最终提交检查，UI 清理 | clean-account 切换与延迟注入 |
| 伪造 postMessage / 宿主脚本 | sender/document/frame/schema/size 校验，页面不能授权限 | 对抗 fixture 与实际注入通路 |
| 文本/导入 prompt injection | 数据与指令分开，LLM 有限 schema，无代码/URL/工具授权 | 否定/引文/伪授权样本 |
| 恶意 ZIP/HTML | 限制解压与路径、文本解析不执行、未知格式拒绝 | 压缩炸弹/穿越/编码/重复冲突样本 |
| 同名目标/外部改名 | 唯一 conversation、原名 precheck、post-read、UNKNOWN | 单独 native-write live 套件 |
| DOM 更新/隐藏租约失效 | 自有样式可撤、能力级退回、刷新逃生不自动刷新 | 真实 MV3 lifecycle 与 host 变体 |
| 多扩展互改 | 每块区域一个 owner，冲突退让，单一原生 writer | PAIA/ACS/CTM 共存矩阵 |
| 模型/同步泄漏 | 最小证据、独立授权/预算、服务端保留披露、客户端加密可选 | egress ledger 与撤权/密钥测试 |
| 导出/诊断泄漏 | 无真实标识/正文/密钥/全页快照入公开仓 | 人工内容审阅和范围检查 |

页面 bridge nonce 可以帮助关联消息，不能单独证明页面未伪造数据；Shadow DOM 不能代替可信授权。采集到的原生链接只经严格同源/路由校验使用，不提供任意 fetch 执行器。

## 5. 原生改名独立通道

默认关闭。授权只覆盖指定账户/空间/对话的旧名→新名、操作类型、次数、有限有效期；整理显示的同意不包括移动/删除/归档/发送/分享。Chrome 没有“只允许改这一个标题”的细粒度安装权限，因此产品的可信 UI、执行器、审计和测试必须共同约束。

状态：DRAFT → REVIEWED → AUTHORIZED → PRECHECKED → EXECUTING → VERIFIED / FAILED / UNKNOWN；另保留 CANCELLED、REVOKED、CONFLICT、NOOP 的终止信息，不伪装成功。

执行前重读 scope、conversation、当前原名、路由/渲染归属、唯一菜单/编辑框及用户活动。旧名变化、目标不唯一或操作有竞争就停；默认串行，单个成功核验后再继续有限批次。DOM 比较不是服务端原子 CAS，仍有最后时刻并发窗口。

只有同范围同对话读到预期新名才 VERIFIED。点击/回包/超时不等同成功/失败；UNKNOWN 不盲重试，先做无副作用 reconciliation。中途撤权停止剩余项，报告已成功/未知/未执行清单。

撤销是新写入与新授权，只有当前原名仍等于这次新名才提议旧名；用户后改时保留冲突。导入/恢复/同步不能自动执行计划，Agent 不许失败后自由探索控件。R0 不执行任何真实改名，此专题到 E 阶段单独批准。

## 6. 原生 UI 与异常恢复

受控原生切换撤销自有 DOM/属性，不重载、不发送、不读取或复制原生草稿，不恢复整份旧 style 覆盖宿主更新。原生聊天节点与工具 portal 保持原 owner。

浏览器禁用/卸载可能不运行清理；不能承诺即时百分百无残留。验证自主失效样式/租约及可达逃生，明确恢复时间、残留和功能影响；原生刷新需用户主动，不能为了外观恢复自动刷新有草稿/生成任务页面。

测试 worker 终止、重连、reload、disable/re-enable、页面冻结/唤醒、SPA 重建、后台节流、CSS 失败和减少动态。需要分别记录原生可用、布局干净、数据保留；其中一项通过不能覆盖其他项。

## 7. 资产恢复、撤权与同步

派生资产备份、restore dry-run、迁移前恢复点、损坏拒绝和配额故障处理属于基础，不是商业附加品。用户原生内容从不由这些动作删除。

撤回内容权限停止任务并使对应证据/索引/向量/AI 结果失效或按明确策略清除。人工独立编辑是否保留要在 UI 说明，不任意抹去。源已删除而派生名仍敏感时可遮蔽，不能透过旧缓存绕过当前限制。

备份默认最小组织/引用；正文另选。restore 不继承 live binding、云执行权、native grant、待执行重试。跨 scope 先隔离核对；恢复失败保留原库。

同步采用独立授权与明确密钥/元数据/保留政策；端到端加密同步不等于云模型看不到获准发送的明文。撤权设备拒绝、tombstone、防时钟覆盖和人工冲突保留均须实测。无用户批准不选择供应商、收费或创建账户。
