# 原始用户发送时间：专项来源复核

基线：PR #14 a68fd07aeec5ba2cc9ff4e9754c5aa294b7e287e，正式src/simulator不变。当前任务是补充来源验证，不重跑R0或合成工程。

| 来源 | 上一轮实际检查 | 上一轮未检查 / 本轮增量 |
|---|---|---|
| 可见消息DOM | 三条本轮合成user；time[datetime]；根/后代包含timestamp、created-at、sent-at、datetime的属性名 | camelCase、create_time、其他时间字段/显示文本语义需要更宽的检测；无字段不等于无服务端时间 |
| structure.js | visible role-root的time后代；仅根上有限data-时间属性；返回聚合计数 | 不是完整时间来源探针，不含create_time/camelCase/服务端响应/初始化数据 |
| 页面可见初始化数据 | NOT_RUN | 本轮仅浏览器内筛选字段名/类型，关联自己合成消息；不输出或检查认证/账户值，不取全页面/全脚本快照 |
| 正常交互第一方响应 | NOT_RUN | 本轮被动监视自己的自然发送/刷新；只增量抽取必要消息元数据，不主动请求历史，不保存完整响应/HAR/请求/认证头 |
| HTTP Date / 本机时刻 | 本机UTC明确只是观察时间；HTTP消息级时间未查 | 单独区分响应时间、接收时间、消息级字段；服务器响应字段不自动证明其为服务端生成的原始用户send time |
| 刷新/重新打开 | 一条三轮访客会话；卸载探针后刷新丢失，后续Back连带失败 | 本轮无扩展、探针加载、卸载三个条件，各使用一条新合成消息；独立比较Back（刷新前）、刷新、重新打开 |
| 账户持久历史/Project/官方clean导出 | NOT_RUN | 本轮继续不登录、不访问内部历史；只列精确待授权范围，不断言所有来源不可行 |

旧报告的限定结论保持：只能否定上一轮实际检查的可见DOM渠道足以满足合同，不能否定所有匿名渠道。当前授权扩大到必要的页面初始化与自然网络响应；不得用时间邻近性代替消息role/ID/会话关系或服务器语义。
