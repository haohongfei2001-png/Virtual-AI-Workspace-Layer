# 主题识别、智能命名与自适应质量评估 · v2.8候选

本轮为算法规格，不调用模型，不接入运行时分类。三项机制规范见[CORE_MECHANISMS_V2_8](CORE_MECHANISMS_V2_8.md)；原D1/D2样本与结果保持历史证据，不换标签宣称升级。

## 1. 当前事实与缺口

PR #12的`experiments/d12/rules.mjs`仅接受精确中文模板“请继续梳理/整理「对象」的{六种任务}。”，要求已知唯一同名主题，且只输出预览。1200模板结构/保护测试不等于通用语义质量，16.67%覆盖也不证明全量自动主题成立。代码的candidate actor不能CREATE_WORKSPACE，更不存在完整自动拆合引擎。

v2.8需要补的是：单对话新主题发现、事项/目标判别、同名歧义、已有主题稳定归属、多主题及拆合建议、真实中文评测。底层人工创建、稳定ID、CAS/lock/exclude继续复用，不重做数据层。

## 2. 归属算法的具体管道

**输入资格**：当前scope/epoch、授权来源与用户角色、明确原生引用、最小EvidencePack及缺失信息。默认不取助手正文/项目文件/未发送草稿；需要额外内容须独立授权。语义不确定与时间未知分开处理，不能因为没sentAt就伪造时间，也不因此拒绝用户手工归属。

**意图先行**：用户从主题内新建、人工include/exclude/lock、手工升格为主题，直接决定本地关系。模型不能复审为“禁止”。对用户已选但内容偏题，仅提出相关片段或其他归属建议。

**召回**：规范化匹配用Unicode、中文字符n-gram/分词、用户确认的中英别名、显式前序/系列；显示保留原用字。原生Project名弱先验，时间邻近/同开只是临时工作集线索。top-20为起始实验预算，可选embedding补召回，不对100k两两调用模型。

**判别**：识别object、goal/output、task、continuation/branch、negative qualifiers与coverage；区分同一对象不同独立目标、不同名字同一目标、引文/否定/模板以及短暂插曲。输出EXISTING/NEW_THEME/MULTI_TOPIC/UNKNOWN。至少列出能支持和反驳归属的实际证据ID；没有证据就UNKNOWN，而不是随机置信度。

**自动门槛**：只对已有、无人工冲突的主题考虑自动Placement；用独立校准集建立score→实际正确率映射，并联合次优margin和支持覆盖设置阈值。模型自报confidence不参与授权。新主题/拆合/批量改名默认预览且有target revision；未达质量目标保留建议模式，不以空的全自动覆盖虚称98%。

**提交**：SuggestionBatch携带scope、目标/证据revision、fingerprint、policy/model版本；页面文本和模型输出均不赋actor权限。仅用户接受或已批准的受限自动Placement策略触发本地受控命令。候选不能创建原生Project、发送消息、改原生名、选默认共享项目或开启云推理。

## 3. 单窗口、拆分和合并的判据

单窗口：人工发起无数量门槛；系统建议需要可独立继续的事项/成果，不要求一定两条聊天才配存在。一次性问答可以未归类，不能自动每聊一张卡。单窗口主题和空主题不会被自动“清理”。

拆分：先证明目标分化和稳定成员边界，再确认用户分别继续工作的价值。窗口多、主题卡太高、自动H不够短不是依据。合并：证明同一事项，检查负约束和人工名称差异；同名或共享Project不够。批处理预览中列出冲突，但不在日常界面堆标签/层级。

多主题长对话先允许多个Placement和手工片段；不默认拆原生消息或改写标题。主题identity随时间稳定；新版模型只影子重算候选，不全库新建ID。拒绝指纹持久化，新的明确证据才重提，不把单例纠错泛化为禁词。

## 4. 名称与系列保持既有上限

派生名=对象＋任务＋必要限定＋有证据的系列编号。6–18汉字等效宽度只是设计起点，不机械截断或加长摘要。主题内可省略重复对象前缀；全局查找显示完整身份。原名独立观察，aliases保留，人工改名锁定。

软件版本、文档版本、聊天系列序号不同字段；没有可核验前序不发接续号。旧聊天首次被读到不是“新一代”。用户输入/拖动/定位时不跳标题；模型更新、无关消息或自动调H不触发改名。

## 5. 评测协议

保留原E5≥1000中文优先样本和目标：自动归属precision≥98%、标题接受≥90%、人工保护合同100%。这些是目标，不是本次结论。新增主题发现、误合并、误拆分、长期一致性、纠错复发必须单列；不以一条总体accuracy覆盖高损害错误。

样本至少覆盖：0/1/多窗口、相同实体不同目标、跨Project同一事项、共享Project不同事项、否定/转述/模板/反讽、汉英混写、长对话转题、任务续接vs产品版本、多人共同项目、时间未知与完整、人工排除/旧revision。

真实自然语料只能来自公开许可或单独同意的去敏材料，双人标注与分歧裁定；按用户/目标/系列/时间隔离train/dev/test，固定版本/预算。模板合成用于结构反例，不和真人gold混算置信区间。精度、recall、coverage、margin可靠性、置信区间及UNKNOWN率一同报告。

原D2“holdout40个预览无错误”不可继承为v2.8语义认证；要报告同数量未自动处理的案例。收益用原生/规则/模型同任务交叉测试，找回时间、错开窗口和周纠错成本为指标，原30%/2分钟目标保持待验证。

## 6. 自适应H不是AI分类

H选择器完全确定性，使用可靠的N(7/14/30/60/90)及数据完整性；不让模型凭“你似乎很忙”缩短跨度。主题定义和time过滤独立；分类改变计数后冷却，防“拆主题→缩H→卡数变少→合并”的反馈循环。

评估P28-A时比较固定30、候选自动、人工固定三组；同时统计找回时长、漏找/误藏、自动改变次数、撤销率、窗口外引用的可达性。至少覆盖稀疏、均匀、突发、全部近期拥挤、全部跨度同数、未知覆盖、导入/拆合及长历史浏览。

5–10主题舒适带、loss中拥挤权重2、7日评估/两轮确认/14日驻留等都是参数候选。没有真人效果数据时不能宣布最佳；小规模设计算例只检查逻辑与反例，不算用户研究或生产benchmark。

## 7. 模型、成本与隐私边界

规则和手工路径始终可用；embedding/端侧/云LLM是后续可选，不为此轮指定供应商或收费。模型成本=输入/输出/向量/网关等按实际报价核算，去重缓存和有界重试，不把历史示例当当前价格。缓存包含scope/授权/evidence/model/policy/target版本；撤权清依赖但不清独立人工资产。

Native Project创建是能力验证＋确定性受限执行，不是给Agent自由浏览权限。详细写入与恢复见[安全规格](PRIVACY_SAFETY_RECOVERY.md)。
