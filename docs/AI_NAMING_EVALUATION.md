# Pro智能组织与命名：保留目标，Free完成后实施

本专题只规定Pro及其未来共享影响，不是Free准入任务。Free不调用AI、不创建虚拟主题、不显示派生名；它的活动、自适应、原生清单与恢复独立完成。唯一执行入口仍是[DEVELOPMENT_PLAN](DEVELOPMENT_PLAN.md)D1–D5及B3.P/C.P。

## 1. 既有成果与真正缺口

`experiments/d12/rules.mjs`当前是限定明确中文模板与唯一已有主题的影子预览。1200模板结构测试、16.67%覆盖不能认证通用自动归类、新主题发现或真实用户接受。保留原样本、代码、反例和报告；后续不用重新从零发明B3人工锁/CAS/别名系统。

Pro首先处理经共享事实层确认Membership=NONE的对话；UNKNOWN不能被当NONE扩大覆盖。AI可以生成VirtualTopic、虚拟组名和DerivedTitle，既不移动原生Project，也不改nativeTitle。未归类/失败/预算不足的对话继续显示原名。真实Project的默认原名和成员仍由Free管理，显式跨Project语义视图保留为Pro高级模式。

## 2. 分层实现

EvidencePack必须含当前scope/epoch、授权来源、原生引用、已发送用户输入/原名/别名/明确前序、证据缺失和target revision；默认不读取助手正文/Project文件/未发草稿。内容中的指令或授权语句不成为执行权。

先硬约束人工include/exclude/lock与确认关系，再识别同一工作对象/目标/成果；任务分面、continuation/branch/similar分开。原生Project名弱先验、同时打开仅工作集线索，不靠同词/时间邻近生成长期主题。

召回先词法/中文n-gram/用户确认别名/Series，再可选多语言embedding，困难少量候选才可用云模型。top-20是初始预算可调，不对100k两两模型比较。输出只限已知ID、标题、主题建议、真实证据引用和不确定原因；禁止任意URL/代码/native grant。

输出EXISTING/NEW_TOPIC/MULTI_TOPIC/UNKNOWN。新主题可以单窗口，不因数量剥夺资格；空虚拟主题可以是人工资产。长期目标未分化的大量窗口先用系列/查找/工作集，不强拆；同名主题合并必须核对意图和负约束。

## 3. 自动收录与人工控制

运行模式依次为shadow、可预览建议、经独立质量门槛允许的可逆自动应用。自动应用需用户开启范围、已校准误差-覆盖曲线与候选差距，不能把模型自报confidence当授权。此路径应最终减少日常管理，不永久要求每条聊天人工审批；未达自动质量时不能通过降低断言宣布全自动完成。

已有人工归属/名称/排除/锁优先。建议带scope/授权代际/evidence hash/model版本/baseRevision，迟到结果不得覆盖人工改动。用户否决保存提案指纹，出现真实新依据才重提；不以某一拒绝泛化成所有同词禁用。

拆合采用明确成员计划、用户选择保留ID、别名/redirect/负约束映射、目标CAS与安全inverse。原生Project不拆、不创建、不删除；虚拟成员变化不制造活动时间。成员真实移入Project后，默认无项目虚拟显示失效但保留人工资产，不逆向移动原生。

## 4. 名称与系列

派生名=对象＋任务＋必要限定＋有证据序号，6–18汉字等效宽度是目标而非硬截断。保留原用字、数学符号、中英实体及历史aliases。主题内省略前缀属于显示上下文，不是两套ID。原生名始终存为事实；Free不从DerivedTitle读取。

人工改名锁定；无关消息/新模型/调整H不得触发漂移。产品版本、文档版本、会话Series编号分别存，整数元组而非浮点；旧聊天首次出现不自动发新号。多主题长对话优先片段/多个虚拟Placement而非重写整条身份。

## 5. 标注与验收

D1保留≥1000中文优先合格样本目标，另有独立自然语料，按用户/事项/系列/时间拆分，双标注分歧单列。模板可验证否定/引用/旧revision/锁/格式，却不是真人gold。只使用公开许可或另行同意的去敏数据。

对照原始标题/规则/规则+embedding/规则+LLM，报告precision、recall、自动覆盖、置信区间、标题直接接受、Series边正确、误合并/误拆分、无证据改名、纠错复发。原98%归属精确、90%标题接受及人工保护合同100%保持TARGET，不把高精度低覆盖包装成全量智能。
