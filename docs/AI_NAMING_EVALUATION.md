# 自动组织、智能命名与评估

状态：算法设计与拟定目标，NOT_TRAINED / NOT_EVALUATED / NO_PROVIDER_SELECTED。原型中的固定标题和 replayAI 不是模型。来源：原研究 §7–9、§17。

## 1. 分层算法

输入是带来源的 EvidencePack：scope/epoch、对话 ID、原名/已知 Project、首个明确任务、后续目标/纠正、明确前序、最近与主任务有关的用户输入、coverage、人工约束和 base revisions。最小必要取样并记录缺失/截断，不把首尾几条称为全文理解。

先在已授权范围中执行硬约束：账户、人工 include/exclude、标题 lock、已确认系列。再识别是否同一事项，然后判断任务分面与 continuation/branch/similar，最后决定 auto-apply / suggest / unknown。Project 名仅弱先验；时间接近和常一起打开主要服务临时工作集，不强合并长期事项。

候选先用词法、确认别名、显式系列和人工归属；再按需多语言 embedding；只对困难候选用云模型。原研究 top-20 为实验起点，不是已测最佳值，不做全历史两两 LLM 比较。

模型输出限于候选 ID、facet、title、证据引用、歧义原因；拒绝未知引用、跨范围对象、任意 URL、可执行代码/工具调用或新权限。模型自报 confidence 不可直接作为自动阈值。实际门槛根据标注和误差-覆盖曲线校准。

## 2. 文本与命名策略

匹配侧可做 Unicode 规范化、中文分词/字符 n-gram、繁简/英文别名；展示保留原用字、稳定产品名、数学符号和人名。引用中出现实体、长模板或否定“不是 PAIA”不能被当成强事项证据。个性化以明确纠错为主，不把访问次数当认可。

名称是对象＋任务＋必要限定＋可选序号。短标题目标 6–18 汉字等效宽度只是起点；同名时优先任务限定，再有证据的分支/序号，不用机械截断。“PAIA 输入板设计/思想库设计”优于两个“PAIA 设计”。

nativeTitle 只观察；displayTitle 有 owner/revision/lock；历史 aliases 追加保存。人工改名锁定，AI 只建议。初始稳定命名后，无关新消息不触发重命名；真正主任务迁移、冲突或明确用户要求才提议改名。多主题长聊天通过 EvidenceSlice/片段解决，不用最新一句覆盖全局身份。

系列证据：用户明确前序 > 已确认真实关系 > 已确认系列中的明确继续 > 仅主题相似。最后一项不可发序号。产品 release、文档版本、聊天序号不同字段；整数元组而非浮点；旧历史首次观察不是新序号。编号冲突暂保留未编号/候选，人工纠正不自动重排全系列。

## 3. 稳定提交与解释

候选进入 SuggestionBatch，Reducer 在当前 scope/epoch、consent、baseRevision、人工约束下提交。用户已经改名、撤权、切账户、删除证据或改变归属时旧结果作废。

自动加入长期工作区门槛高于相关建议；稳定人工/确认关系不因一次低分删除。拆分/合并/批量改名必须预览；模型升级先 shadow evaluation，不全库重跑覆盖。解释读取记录过的证据，不再生成一段事后理由冒称算法依据。

缓存键包含 evidence hash、scope/consent generation、model/schema/policy 版本及目标 revision。权限撤回/证据删除使依赖结果失效；模型失败不清空既有组织。界面导航不等待模型。

## 4. AI 与 Agent 的分工

规则/词法是总可用底座；端侧 embedding/小模型可降低数据外传但须测下载、内存、电耗和中文质量；云模型只处理获准最小困难项；确定性自动化执行批准的具体原生改名。通用 Agent 只辅助提出分析/兼容修订，不作为生产自由操作器。

原研究关于 Chrome Prompt API 支持语言、ONNX Web 运行路径及 Sign in with ChatGPT 的内容保留为 S18–S21 时点记录，不作为本次承诺。当前未选端侧模型、云模型、供应商或凭证方式；官方身份/用量路径也不能授权历史读取，更不能代替网页账户绑定。

## 5. 成本与性能预算

C = 输入 tokens/1M × 单价 + 输出 tokens/1M × 单价 + embedding + 有界重试 + 网关/存储/支付/支持。研究示例为 1,000 条 × 800 输入/60 输出，即 0.8M/0.06M；假设单价 1/5 元每百万时为 1.10 元，仅算术不是供应商报价。

按批/日/月/并发/重试设置上限，预览复用缓存，不暗中重复收费。UNKNOWN 请求先查明结果，不盲重发。模型服务不可用时规则与人工作品正常。

10,000 × 384 维 float32 原向量约 15.36 MB，不含索引/正文/模型/运行内存。100k 是压力档，不是首发完整正文和模型规模承诺。

## 6. 评测协议

E5 至少 1,000 条中文优先样本，优先合成与后续单独同意数据；不能只测开发者 PAIA 词典。覆盖否定、引用/模板、同名实体、反讽、多项目、短句“继续”、主题变化、旧聊天首次出现、系列与产品版本混杂。

允许多重归属与 unknown；两位标注者分歧单列/裁定，不把主观风格差异强判错误。按用户、事项/系列和时间切分，避免相邻续聊泄漏。对照原生名称、规则、规则＋embedding、规则＋LLM；固定语料、模型版本、预算、阈值及设备。

初始目标（均 NOT_RUN）：自动归属 precision ≥98%，标题直接接受率 ≥90%，人工保护断言 100%；同时报告 recall、自动覆盖、置信区间、系列边准确率、无证据改名率和纠错复发率。低覆盖高 precision 不能伪称全量智能；观测零安全事故不能证明未来绝对零。

E6 与原生/主要竞品同任务、随机化或交叉顺序评估，记录找回正确对话/前序/来源的时间、失败、恢复错误与每周纠错。目标中位改善 ≥30%，周纠错 ≤2 分钟是早期假设，不是保证。失败则减少自动范围/修算法，不用更多 UI 掩盖无增益。

E7 重复同证据、无关消息、模型升级和人工纠错测试，稳定名字与 include/exclude/lock 不漂移。所有实际模型质量、成本与用户收益均须另行真实实验，不能引用原型 PASS。
