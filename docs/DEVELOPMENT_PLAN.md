# 完整旗舰开发计划

2026-10-10 增量；原 A–G 路线与任务 ID 保留。当前只允许设计与原型，正式实施/R0 宿主探针未授权。唯一状态见 [STATUS](STATUS.md)。[CORE_EXPERIENCE_V2](CORE_EXPERIENCE_V2.md) 是新增核心规格，不是后期美化备忘。

## 1. 执行原则

第一轮验证可能改变架构的能力，不直接搭正式产品骨架。当前三项核心要求必须前置：真实 ChatGPT 视觉/交互跟随、主题级卡片、可靠用户发送时间与日历窗口。区间活动算法不使用 LLM；先有时间证据和范围，再有活动投影。

C 的交互评审、D 的合成标注可与 B 的无依赖部分并行。E 原生写入、F2 同步、G 生态不阻塞已验证的只读工作空间；PAIA 运行共存不推迟到可选数据集成阶段。精确像素或云供应商待定不阻塞 R0；时间证据缺失也不能通过访问时间兜底。

通过含义分源码、合成浏览器、真实宿主、模型与用户证据。未知/受阻不算失败或通过。阶段表不授予私人账户、付费、凭证、其他仓库、部署或原生写入权限。

## 8. G：可选生态

G1：独立可用后再设计 PAIA 最小证据协议，双方独立同意/白名单/版本，无共享可写 owner。PAIA **运行共存**已在 R0/C，不挪到 G。

G2：官方身份/计划用量与商业/扩展资格定向核实；不默认授予网页历史或证明当前宿主身份，未成立不阻塞其余能力。

## 9. 原 E1–E10 目标保留

E1 数据/条款：至少一条可持续、有覆盖和权限说明的路线；E2 范围：指定实验零跨范围泄露，不营销绝对安全；E3 原生功能：发送/停止/编辑/分支/附件/模型/Canvas/语音无新增阻断；E4 兼容退出：准确记录受控和真实disable链；E5 命名：≥1k样本、归属precision目标98%、标题接受90%、人工保护断言100%，同报覆盖/区间；E6 找回：中位时间改善目标30%、错误不增、每周纠错≤2分钟为假设；E7 稳定：无新证据不漂移；E8 改名：无错误目标、逐项终态、UNKNOWN不盲试；E9 性能：10k导航p95<150ms/搜索首屏<300ms为目标，100k为压力档；E10 恢复：人工资产可回读、损坏拒绝、无旧副作用重放。

新增 T1–T8：日历边界/月末/闰年/连续段；时区/DST/午夜；消息级时间真实性/部分覆盖；跨区间存在性；主题与行同步；历史/未知/固定/current例外；切换不改源事实；原生视觉/节点/PAIA真实共存。算法类可先在合成材料验证，来源/宿主类仍需R0/LIVE_HOST。

所有产品目标数字仍为 TARGET/NOT_RUN。v2 的 37/37 仅是文档原型的实际模拟记录，不能填进这些正式门槛。
