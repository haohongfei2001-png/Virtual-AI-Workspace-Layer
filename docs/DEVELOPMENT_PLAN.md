# VAIWL 唯一开发计划：Free 完整交付 → Pro 智能增强

整合日期：2026-10-13。核对基线：PR #15 `fd5df2be787f8eef053de65965395d7eeea1a80d`；父 PR #14 `0b07455a09b4f2ae2d756ffca5a868305815e424`。本文件是唯一执行路线，原 A–G 和任务 ID 全部保留；`.F`、`.P`只是原任务内的交付切片，不另建 Free/Pro 两份计划。

用户已确定 Free-first / Pro-later；不再等待审批旧版虚拟主题作为 Free 默认的 D28 决策。当前交付是文档正文整合，不是功能实现或真实环境验收。按[AUTHORITY](AUTHORITY.md)区分本轮仅文档权限与将来实施、真实账户、原生写入、模型、合并和发布许可。

## 1. 唯一产品目标与任务归属

- **Free**：现有界面不重设计；项目卡严格对应真实 ChatGPT Project，键为 `(scope, nativeProjectId)`，项目名和聊天行均显示原生名称；无 Project 聊天是同等重要的独立紧凑列表。范围/成员正确、活跃准确且可用、自动进入较早区间、已知历史不失联、原生功能完整、持久恢复构成完整产品。
- **共享底座**：账户/原生事实、证据、IDB、CAS、分片、恢复、搜索、工作集、用户手选片段、时间策略、性能和原生适配。已有非 AI 功能继续复用，不能因分级被删除或强制付费。
- **Pro**：在完整 Free 上优先为确认无 Project 的聊天提供 AI 虚拟收录、虚拟主题和派生标题；保留系列、智能拆合、人工纠错/锁/排除、显式跨 Project 语义投影、端/云模型及原高阶目标。未归类余项必须仍可见，原生名称/成员不改。
- **独立可选能力**：VAIWL 代理原生改名/自动创建、跨设备数据同步、PAIA 数据协议、收费服务另有许可。它们不成为 Free 正常原生新建/搜索/使用的前置条件。原生创建入口由用户操作不等于扩展自动写入。

规范职责：[CORE_MECHANISMS_V2_8](CORE_MECHANISMS_V2_8.md)定义机制，[FREE_PRO_PRODUCT_SCOPE](FREE_PRO_PRODUCT_SCOPE.md)定义功能分级，[DATA_MODEL](DATA_MODEL.md)定义数据合同，[FREE_PRO_ACCEPTANCE](research/FREE_PRO_ACCEPTANCE.md)定义验收。本计划定义顺序、依赖、负责人边界和停止条件；引用不形成并行路线。

## 2. 已有工程如何复用：不将阶段全部重置

B1–B5、C1–C5可独立部分、F1已有隔离合成 Chrome / IDB / MV3 证据，按原精确源码保留。D1/D2为1200模板影子预览，非通用自动分类；PR #14访客调查的原始用户发送时间及覆盖仍 UNKNOWN，不能扩大为全部渠道 NO_GO 或登录态已通过。

源码核对表明，当前 `src/data/state.mjs` 只允许 `none/synthetic` channel；旧引用内容变化会产生 `native-reference-conflict`；`evidence.mjs`按 `workspaces/placements` 构造主题并优先 `identities.title`；`projection.mjs`固定除以30；`simulator/service.mjs`是合成种子与身份。**因此 Free 不能靠关闭 AI 开关或改几行显示名称完成。** 需要新增原生项目/成员观察更新与 Free 投影，同时复用底层事务、组件、分区和测试器。固定代码/证据及差额见[基线表](research/V28_BASELINE_AND_ACCEPTANCE.md)。

不删除旧 Workspace/Placement/DisplayIdentity、Series研究、D实验、v2.7原型和工程失败记录。旧 `.28`中自由主题/多 Project/自动创建任务转入相应 `.P`或 E 可选能力；日期参数、恢复与安全部分进入 `.F`。旧65项验收在基线表逐组映射，不强迫 Free 先完成全部 Pro 用例。
