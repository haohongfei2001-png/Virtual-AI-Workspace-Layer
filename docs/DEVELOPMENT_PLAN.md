# 完整旗舰开发计划

状态：PROPOSED，当前仅文档授权。依赖顺序来自原研究 A–G，不将目标缩成 MVP。任务编码用于交接，不代表实施已经开始。当前唯一下一任务见 [STATUS](STATUS.md)。

## 1. 执行原则

第一轮先验证可能改变架构的能力，不先创建完整产品骨架或重做原型。每项交付注明源码/fixture/真实宿主/模型/用户证据等级；未知和受阻不算失败，也不算通过。

阶段允许独立工作：C 的交互评审、D 的合成标注可与 B 并行；E 原生写入、F2 同步、G 生态都不阻塞已证明的只读工作空间。触及的产品决策逐项批准即可，不让所有未决交互阻塞安全研究。

任何任务执行前需适用授权；本表不能授予访问私人账户、付费、凭证、其他仓库、部署或 native write。

## 2. A / R0：架构能力验证

任务书：[R0_CAPABILITY_SPIKE](experiments/R0_CAPABILITY_SPIKE.md)。输出每项 capability 的 GO / LIMITED / BLOCKED / NO_GO 和影响，不输出“全部可行”的笼统结论。

| ID | 依赖 | 交付与验收 |
|---|---|---|
| R0-00 | 独立探针授权 | 清洁环境与权限矩阵、数据/条款渠道登记、实际版本、预定义合成对象；无私人材料 |
| R0-01 | 00 | 账户/组织/文档绑定；正反切换与异步竞态，未知隔离；不能以 vault 选择替代 |
| R0-02 | 00；live 持久读取须 01 | 路由/用户角色/分支证据、历史发现与 export schema 覆盖；未知历史不补造 |
| R0-03 | 01、02 | 同 scope 普通聊天＋两个原生 Project 的只读聚合/导航，原生归属不变、无上下文合并暗示 |
| R0-04 | 00；live 展示敏感信息须 01 | 原生 DOM 岛、模型/工具可达、切换/worker/reload/disable/freeze/CSS 恢复；与无扩展对照 |
| R0-05 | 04；实际 PAIA 测试另有清洁环境 | PAIA 单独/共同与加载顺序矩阵；零区域争抢/焦点/原生功能新增阻断；不改 PAIA |
| R0-06 | 01–05 各有终态/受阻说明 | 固定实验版本的证据包、支持档位与调整建议、B/C 下一依赖；不得自动开工 B |

R0 失败后的正当路径是禁用危险渠道、缩小可控导航区或限定已验部署模式；若基本身份/数据渠道仍不成立，不发布无缝自动隔离/全量整理。继续的离线工作必须明示不能覆盖该缺口。

## 8. G：可选生态

G1 在独立可用后设计 PAIA 最小证据协议：双侧各自同意、版本与 white-list、无共享可写 owner；当前共存已在 R0/C，不能挪到这里逃避兼容。

G2 单独核实官方身份/计划用量路径及商业/扩展资格；不默认存在支持，不授予历史访问或代替宿主绑定。未成立不阻塞其他完整能力。

## 9. 原研究 E1–E10 验收映射

| 实验 | 归属 | 原拟定标准/输出 |
|---|---|---|
| E1 数据/条款 | R0-00/02、B2、F3 | 至少一条可持续路线，来源/权限/覆盖可解释，无未经确认全量抓取依赖 |
| E2 账户/内容归属 | R0-01/02、B1/C6 | 测试中零跨范围显示/存储/云传/写入；unknown 拒绝，不能宣称绝对零风险 |
| E3 原生功能 | R0-04、C2/C6 | 发送/停止/编辑/分支/附件/模型/Canvas/语音等无新增阻断 |
| E4 兼容/退出 | R0-04/05、F3 | 受控恢复可用；真实 reload/disable 链与刷新逃生有精确记录 |
| E5 命名分类 | D1–D5 | ≥1k 样本；归属 precision 目标98%、标题接受90%、人工保护断言100%，同时报覆盖和区间 |
| E6 找回收益 | D5/F4 | 中位找回时间改善目标30%，来源/系列错误不增；每周纠错≤2分钟为初始假设 |
| E7 稳定性 | B3/D2/D5 | 同证据/无关消息不漂移，人工 include/exclude/lock 均保持 |
| E8 原生改名 | E1–E3 | 指定集合无错误对象写入；每项真实终态；UNKNOWN 无盲重试 |
| E9 性能 | F1 | 10k 引用导航 p95<150ms、首屏搜索<300ms 是目标；100k 压力档非首发全量承诺 |
| E10 资产恢复 | B5/F2/F3 | 人工修改可回读，损坏拒绝，不重放 native/AI 副作用 |

以上数值全为 TARGET / NOT_RUN，除原记录模拟测试外没有已测产品指标。验收失败先确定受影响能力，不降低人工保护或安全标准来提高完成率。
