# 信息架构、页面与关键交互规格

2026-10-10 v2.1 定向纠正。当前时间与信息密度规则见 [CORE_EXPERIENCE_V2_1](CORE_EXPERIENCE_V2_1.md)，覆盖 v2 中按任意区间事件反复列主题、显示每行来源/日期/计数的选择。原生一致性与卡片语言继续沿用 [v2 非冲突部分](CORE_EXPERIENCE_V2.md)。

## 1. 导航结构

入口为新对话、搜索、主题、以前、当前工作集、原生功能和设置/恢复。主题即稳定 Workspace，不另建 PAIA Topic 或无限递归目录。同主题跨原生 Projects/普通聊天聚合，内部紧凑行。既有显式多 Placement 不复制原生实体；本轮不改变此归属规则，只修正按时间的展示。

主题卡片和“不做对话级大卡片”不冲突。相关建议按需出现，不成为永久目录；可选分面不能演变成复杂文件夹。

## 2. 默认主题页

默认最近一个月活跃的主题；每个主题只在按最近可靠用户发送确定的一个时间段出现。卡片头仅主题名、展开控件、按需菜单；对话行仅名称与按需操作。没有发送日期、Project 来源、来源数量、命中/总数、区间外或覆盖徽标。

卡片内默认呈现该主题所属段仍活跃的窗口；旧窗口始终留在该主题“以前的对话”里，点击才显示。时间不能判定的成员用折叠“其他对话”保留，不猜测为旧。无法确定所属段的主题经折叠“其他主题”可访问，不形成审批收件箱。

大量对话沿用可到达末尾的增量展开和单主题聚焦；“显示更多”不带计数。初始4行/后续12行与列数仍是原型解法，不是用户已批准像素。卡片保持克制边界与间距，不加品牌底色、渐变、大摘要。

## 3. 以前与月份隔断

默认不显示日期工具栏、时区、示例今天或每项活跃时间。全局“以前”查看上一段的主题，“更早/较近/回到现在”导航。1/3/12个月与全部历史在按需菜单；默认无需配置。沿用当地今天锚定、日历月夹取与相邻无重叠的后台边界。

主题按最近活动唯一分段，不是按每个月曾经发生的活动重复检索。PAIA 当前活跃就不在上一段；八月的 PAIA 窗口仍在当前 PAIA 卡片内折叠。历史主题内部按其自己的段划分默认/旧/未知成员，不按用户先前查看的其他段拆窗口。

时间切换只换投影，不写 Workspace/Placement/原生 Project，不删除、不生成发送时间。当前对话不关闭，工作集不清空，原生聊天与输入 DOM 不重建。

## 4. 启用与导入

现有聊天上启用时不跳页、不改URL、不抢焦点。先用可验证引用，观察、持久索引、云、改名、同步分开授权。scope 未核验不展示旧 vault；手选 vault 不等于账户认证。

已知引用、主动导出与正常打开逐步补全三条路径保留。导入诊断可以在低频专属流程中说明重复、分支、覆盖与拒绝项，但不把它们铺到日常卡片。批次可预览/撤销；不把文件时间当发送时间，不报告不存在的全账户覆盖。

## 5. 新建与名称

新建时核对真实原生目的地；每次选择或记住默认仍待PD-05。取消日常逐行来源不等于隐藏有真实上下文影响的新建选择。主题不合并 Project 文件/指令/记忆；稳定发送/身份证据后才归类，不持久采集草稿与IME中间文字。

全局名称保留对象/任务/必要限定，主题内可省重复前缀；只做视觉省略。人工名保护、历史别名和外部原名观察保留。输入/拖动/定位期间不变名称顺序。系列区分继续/分支/相似；序号不等于软件版本，整数元组1.9→1.10；旧聊天首次观察不发新号。

## 6. 纠错、固定与撤销

拖入只改派生位置；直接添加或多选确认仍待PD-04。人工include/exclude持久，不被AI加回；单个纠错不泛化。成员改变后重算真实最新活动，不使用分类操作时刻。

固定只生成快捷引用，原型放在侧栏；旧主题不提升到当前卡片区，旧对话不带出父主题。点击可访问但不算发送。解除固定回到原有分段，不能跨scope或权限。

正式撤销使用revision与inverse/冲突处理，不能回滚全库覆盖新编辑。原型快照撤销仅是模拟。派生撤销不撤原生改名，删除主题不删聊天。

## 7. 搜索与当前工作

搜索原/派生/历史别名及获准输入；可以包含以前和未知记录。结果不逐行显示来源/日期/数量，不为未读内容生成摘要。点击旧窗口不使主题重激活。精确片段需唯一message/branch证据，否则回原生查找。

当前聊天页不加VAIWL来源行或时间状态。离开聊天查看主题时，简短“正在查看＋对话名”保留入口；聊天页不重复这条提示。工作集保存引用/顺序/当前项/必要窗口关系与有效锚点，不保存草稿、生成任务或Agent状态。失败引用保留，不静默删除。

## 8. 原生进入与恢复

聚焦既有tab先匹配scope/原生空间/conversation，保留修饰键/中键/复制链接。原生来源仍在底层记录；同卡显示不合并权限。只撤除自有挂载/属性，不导航、重发、清空输入；原生title保持真实状态，已独立授权的原生改名不随派生开关撤销。

适配失效局部退回，不空白等待AI。真实worker/reload/disable/re-enable/freeze/节流/CSS/PAIA共存仍需独立验证；不能自动刷新工作页面制造通过。v2.1只验证模拟节点不被重建。

## 9. 原生视觉和无障碍

当前ChatGPT视觉角色/菜单仍是参照，第三方身份始终可见；精确font/size/radius/gap/color/motion依R0真实样本，不以原型当平台像素契约。菜单锚定/避边、Esc/外点关闭、方向键与焦点返回；窄屏先让导航；拖动有按钮等效；标题/选中态可读屏。目标对比4.5:1、200%不遮挡、减少动态无信息丢失。物理IME与完整原生验收未完成。
