# 信息架构、页面与关键交互规格

2026-10-10 v2 增量。[CORE_EXPERIENCE_V2](CORE_EXPERIENCE_V2.md) 为原生一致性、主题卡片和用户发送时间的核心规范。三项要求已经明确，精确像素与默认动作仍受 [DECISIONS](DECISIONS.md) 约束。旧原型证据见 [PROTOTYPE_EVIDENCE](research/PROTOTYPE_EVIDENCE.md)，新原型见 [v2](prototypes/v2/prototype-v2.html)。

## 1. 导航结构

入口为新对话、搜索、主题、当前工作集、原生功能和设置/恢复。主题即稳定 Workspace，不另建 PAIA Topic 或无限递归目录。主题卡片可聚合不同原生 Projects/普通聊天；内部仍为紧凑行。单个对话多个 Placement，不复制原生实体，不用 memberships[0] 强定唯一访问语境。

原来的“紧凑列表、不做卡片墙”仅排除**对话级大卡片**，不排除主题级卡片。相关建议按需出现，不成为第五套永久目录。现有可选分面仍可在需要时使用，不能让主题卡片变成多层文件夹。

## 2. 主题主视图

默认最近一个月，只将存在可信用户发送事件的主题放进活跃区；卡片内只默认展示命中区间的对话。非活跃/区间外对话在卡片内折叠；非活跃主题统一折叠。未知时间单列可展开，不能当作“不活跃”。人工固定区只作为显式可见性例外，不改变活动统计。

卡片头含主题名称、展开状态、命中/已知计数、按需菜单；内部是标题、必要来源、该区间用户发送日期。卡片用克制边界/间距分隔，不用 PAIA 品牌底色、渐变或大摘要。当前选中与时间活跃分开表示。

建议初始4行、后续12行增量，达到完整集合末尾；几十个对话可单独查看同一主题，仍同一ID。不以截断冒称全部。折叠/展开状态独立于实际归属；当前已打开聊天不因折叠被关闭。具体列数、数量与头部点击行为待评审。

## 3. 时间控件与一致更新

提供最近1月、3月、1年、全部，以及向前/后逐段、回到最近。始终显示实际日期，按用户当地今天减日历月，不按自然月/固定天数。严格边界、月末夹取、时区/DST见核心规范§4。

时间切换同时重算主题状态、卡片区域、内部对话集合和计数；不改主题归属，不删除、不自动归档，也不生成发送时间。当前对话/工作集/人工固定保持访问；未知记录在全部历史中可见。窗口变化不重建原生聊天/输入节点。

访问历史对话不会使其成为活跃；“正在查看 · 区间外/时间待确认”提供返回入口。最新一次消息在10月的对话可能在8月也有输入，查看8月必须通过区间事件存在性命中，而非只看 lastUserSentAt。

## 4. 首次启用与历史整理

在现有 ChatGPT 对话启用时留在原处，不跳仪表盘、不改URL、不抢输入焦点。先用可验证引用，页面观察、持久索引、云、改名和同步分别授权。宿主 scope 未核验不显示旧 vault，选择 vault 不等于账户认证。

历史仍有已知引用、主动导出、正常打开时逐步补全三条路径。导入显示范围、重复、未知字段、分支、Project与时间覆盖；不把文件时间当消息时间。批次预览/撤销不是日常审批收件箱；账户总量未知只报告已知数量。

## 5. 新对话与名称

新建的实际原生目的地可见且可改；记住默认或每次询问仍待PD-05。派生主题不赋予其他Project的文件/指令/记忆。稳定发送/身份证据后才能归类；草稿、IME中间文字不持久采集。

名称保持对象/任务/必要限定，工作区内可省重复前缀；视觉省略不截断保存。人工名锁定，历史别名可找；外部原名变化更新观察并暂停原生自动化，不猜作者。生成/输入/拖动/定位期间不换名称顺序。

系列区分明确继续、分支和仅相似；序号与软件版本分开，整数元组1.9→1.10。首次看见旧聊天不是新聊天，不因访问发序号，删除旧项不重排。

## 6. 纠错、拖动、固定和撤销

拖入只改变派生显示；直接添加＋撤销或多选确认仍待PD-04。人工include/exclude持久，不被AI加回；单个纠错不自动泛化至同名事项或全系列。

归属变化后主题依据新成员真实发送事件重算，不把分类操作时间当作活跃来源。固定主题/对话只改变可见性，区间外/未知标记继续保留。固定父主题展示方式见核心规范§7和PD-14。

正式撤销使用revision与inverse/冲突处理，不恢复整库旧快照覆盖后来的修改。原型仍是模拟快照撤销，不能直接迁作正式数据层。派生撤销不撤销原生改名，删除主题不删聊天。

## 7. 搜索与片段

搜索保留原名/派生名/全部历史别名/已授权输入与片段。建议当前区间为初始范围，提供明显的“全部已知历史”逃生，包括区间外与未知；搜索/点击本身不激活。结果显示来源与覆盖，不为未读消息生成摘要。快捷键不抢原生和IME。

片段跳转需验证message/branch与唯一定位；未加载或不唯一时回到原生对话/查找，不点击第一个相似文本。局部片段主题不强迫主标题改变。

## 8. 工作集与原生进入

Conversation身份唯一，TabInstance可多个；聚焦既有tab须匹配范围/原生空间/对话，不只URL。保留修饰键/中键/复制链接的真实语义。

现场保存引用/顺序/当前项/窗口关系/已验证锚点，不保存原生草稿或Agent内部状态。缺失引用保留，不静默filter；去重不关闭用户其他窗口。工作集可跨主题但不能跨未授权scope；不受当前时间过滤强制清空。

## 9. 原生切换与恢复

只撤除自有挂载/属性，不导航、不重发、不清输入。原生title保持实际状态，派生别名隐藏；已独立完成的原生改名不随开关撤销。页面适配失败局部退回，不能空白等待AI修复。

浏览器禁用/卸载后不保证还运行清理JS；刷新是用户可选逃生，不能自动刷新有工作内容页面。真实worker终止、reload、disable/re-enable、冻结、节流、CSS与PAIA共存独立实测。v2 模拟节点保持并不代替这些证据。

## 10. 原生视觉、菜单与无障碍

从首次完整页面跟随当前真实ChatGPT视觉角色，不采用另一套品牌；具体font/size/radius/gap/color/menu/motion需R0测量并按宿主变体验证。第三方身份在桌面/窄屏都可见。原生功能真实可达，不用静态说明冒充模型/工具入口。

菜单就近锚定/避边，Esc/外点关闭，键盘导航和焦点返回；原生输入优先，窄屏先让出导航；拖动有等效菜单；标题/来源/选中可读屏；目标对比4.5:1、200%不遮挡、减少动态无信息损失。精确原生像素与物理IME仍未本轮验收。

v2 实际为1440×1000与390×844等合成页面测试；没有接入真实ChatGPT。原始研究与旧证据完整保留，不因本次视觉变化重写历史。
