# VAIWL Free / Pro 功能归属合同

产品方向已明确：同一代码库、同一A–G路线，先完整交付Free；不再将Pro虚拟主题作为Free默认。机制以[CORE_MECHANISMS_V2_8](CORE_MECHANISMS_V2_8.md)为准，任务仅在[DEVELOPMENT_PLAN](DEVELOPMENT_PLAN.md)。

| 能力 | Free/共享首期 | Pro或独立后续 |
|---|---|---|
| 主页卡片 | 真正ChatGPT Project，稳定原生ID和名称 | 在Free之上可附加VirtualTopic，绝非真实Project |
| Project内窗口 | 只按已核验的原生成员，行用nativeTitle | 默认仍原生；显式跨Project语义投影另开模式 |
| 无Project聊天 | 与项目并列的紧凑列表，全部已知原名、活动/历史/查找可达 | 优先输入AI虚拟收录与派生命名；剩余未归类仍保留 |
| 归属未知 | 可达、待核验，UNKNOWN不当NONE | 不能为了AI覆盖把UNKNOWN当无Project |
| 活跃排序/时间范围 | 原始证据与观察提示分层、可逆判断、自动老化/有界校准；固定/手动/有证据的自适应 | 同一共享能力，不收费锁定正确性或历史访问 |
| 标题与纠正 | 原生改名通过宿主，可靠观察更新；纠正数据识别/显示异常不付费 | 人工派生改名、虚拟归属纠错、锁定、排除、智能拆合 |
| 新Project/新聊天 | 沿原生用户入口和实际权限；不存在先造虚拟主题再强绑同名Project | 代理原生创建/批量改名等E能力另行授权，非自动订阅权限 |
| 搜索/工作集/手选片段 | 原生搜索、已知原名/原生别名查找、既有非AI工作集与选中片段、安全定位 | 语义搜索、派生名、系列/多主题关系附加 |
| 数据/恢复/性能 | 共用IDB、迁移、CAS、备份、安全回退/隐私、无模型启动 | Pro资产保留，不因降级删除或影响Free |
| 模型与商业服务 | 无强制模型/API key/会员网络验证 | 端侧/云模型、质量评估、预算/外传、会员计费分别批准 |
| 同步与生态 | ChatGPT源刷新不是VAIWL同步；PAIA运行共存须测 | 可选加密同步、PAIA数据接口、官方高级生态按原F2/G保留 |

名称、分级是VAIWL自己的产品概念，不等于用户的ChatGPT订阅或Project可用权限。实际宿主不可用的能力不伪造。Free首发不以Pro高级功能、云同步、模型精度或商店付费系统为前置。

Free为可日常使用的完整产品，而非只有预设合成列表的演示。其正式验收包含真实库存/成员、久未发言进入较早区间、手机活动再发现、原生所有权、账户隔离、退出恢复及实际PAIA共存；数据缺失时先可用显示，但相应技术门槛没有因此被解决。

所有先前AI/虚拟主题代码和研究保留。切换Free视图只选择原生事实投影，不删除人工作品、不批量改Project名称、不从虚拟归属迁移真实聊天。旧Pro人工资产的可恢复性属于共享底座，不作为付费惩罚。
